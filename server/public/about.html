About the PHP2Shell check

A free service that tells site owners whether their PHP is still exposed to CVE-2026-109618 and CVE-2026-109619, and what to do about it.

How it works

The check reads the PHP version your server advertises and compares it with the fixed releases. When you confirm that you own the site, it adds one small request whose answer differs between patched and unpatched PHP, and asks for /phpinfo.php and /info.php if no version shows. Nothing is written to your server and nothing is attempted beyond those requests.

The check reports patch state, not exploitability. How hard the flaws are to exploit varies by server setup; the PHP project rates Apache with mod_php as the highest risk, and an unpatched release is worth fixing whatever the setup.

What it cannot see

A server that hides its version and its errors gives no signal, patched or not. Distribution packages may carry the fix under an older version number. The check never reports a site as safe, only what it saw.

Which targets are checked

Public domain names and public IP addresses only, on ports 80, 443, 8080 and 8443. Private, loopback, link-local and other non-public addresses are refused, including IPv4 addresses carried inside IPv6. Each site is checked at most once every few minutes; a repeated request receives the earlier result.

What is recorded

One line per check: the time, the host name or address that was checked, and the verdict. Your own address is not recorded. Lines are kept for 30 days.
